Cybersecurity

I study cybersecurity so I can write safer applications and understand how testers look at systems. Practice happens in labs and on systems I am allowed to test—not on random public sites.

CTF-style challenges are part of that learning (reconnaissance, web issues, Linux). I do not list contest ranks or awards here; those will appear only if I earn them.

  • Web security Common request/response issues, inspection with Burp Suite, and documenting findings.
  • Network basics Host and port discovery with Nmap in authorized environments.
  • Lab workflow Metasploit used only to learn exploitation flow inside legal lab setups.
  • Mindset Permission first, fix and report, no trophy hunting on other people’s systems.
