04 // SECURITY PRACTICE

Cybersecurity & Ethical Hacking

Cybersecurity is fundamental to engineering good software. By understanding attacker methodologies, network packet traversal, and application attack vectors, I build software that resists vulnerabilities from day one.

My hands-on practice is conducted strictly within authorized lab environments, CTF challenges, and controlled sandboxes—focusing on ethical disclosure, proactive hardening, and security audits.

  • Web Application Security Analysis of OWASP Top 10 risks (SQLi, XSS, CSRF, broken authentication) and traffic inspection via Burp Suite.
  • Network Reconnaissance & Auditing Port scanning, service fingerprinting, and subnet reconnaissance using Nmap in authorized lab topologies.
  • Penetration Testing Frameworks Familiarity with Metasploit fundamentals and payload execution inside isolated testing environments.
  • Security Mindset Defensive coding principles, input validation, principle of least privilege, and responsible vulnerability disclosure.
